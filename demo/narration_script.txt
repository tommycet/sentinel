Scrolling to the architecture section.

The architecture section shows the signal flow in IBM Plex Mono typeface. An alert arrives through a Signos webhook, passes HMAC SHA-256 verification, gets stored in a SQLite incident database, queries the AgentLineage graph, triggers the credential revoker for vault access and database sessions and API tokens, and finally exports OTLP traces back to the Signos collector. One signal path with no hidden hops.

Now into the capabilities section.

Capability one — AgentLineage. Every incident links to the original Hermes brain capture artifact plus the LLM response, vault read, database mutation, and external API call in exact chronological sequence. Query by incident ID or model provider.

Capability two — cross-agent contamination detection. If agent A's vault read leaks into agent B's prompt through an unintended context leak, the lineage graph flags the shared credential hash and raises a cross-agent audit flag automatically. No manual correlation required.

Capability three — revocation. A single POST request to the circumflex incident I-D release endpoint kills the full blast radius. It revokes the vault key, kills the database session, cancels the external API token, and writes an OTLP span. Each revocation is confirmed with a revoked equals true line in the audit log before the endpoint returns 204 no content.

The hackathon differentiator is the structural advantage. AgentLineage is impossible for LLM-only competitors like Langfuse, Phoenix, or Breadcrumbs because they lack Signos unified telemetry store. Sentinel uses the exact same OpenTelemetry pipeline as the agents it monitors, so lineage is a trace lookup, not a separate infrastructure.
