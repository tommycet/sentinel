# Deploy Spec — Foundry Reproducible Deployment

## Purpose
Deploy Sentinel alongside SigNoz using Foundry, with full reproducibility per hackathon rules.

## Foundry Overview
Foundry is SigNoz's deployment CLI that:
- Takes a `casting.yaml` declaration
- Generates Docker Compose files (or K8s manifests)
- Deploys SigNoz + optional components (MCP server, etc.)

## casting.yaml

**Location:** `casting.yaml` (repo root)

**Minimum Content:**
```yaml
apiVersion: v1alpha1
kind: Installation
metadata:
  name: signoz-sentinel
spec:
  deployment:
    flavor: compose
    mode: docker
  mcp:
    spec:
      enabled: true
      env:
        # Make MCP server export its own telemetry to SigNoz
        OTEL_EXPORTER_OTLP_ENDPOINT: http://signoz-ingester:4317
```

## Adding Sentinel to Foundry

**Approach:** Use Foundry patches to add Sentinel as an additional service.

**Patch File:** Add to `spec.patches` in `casting.yaml`:
```yaml
spec:
  patches:
    - target: "deployment/compose.yaml"
      operations:
        # Add Sentinel service
        - op: add
          path: /services/sentinel
          value:
            image: sentinel:latest
            build:
              context: .
              dockerfile: deploy/sentinel.Dockerfile
            ports:
              - "8090:8090"
            environment:
              - SENTINEL_WEBHOOK_SECRET=${SENTINEL_WEBHOOK_SECRET:-changeme}
              - SENTINEL_DB_PATH=/data/sentinel.db
              - SENTINEL_OTEL_ENDPOINT=http://signoz-ingester:4317
              - SENTINEL_DRY_RUN=true
            volumes:
              - ./sentinel-data:/data
            depends_on:
              - signoz-ingester
              - signoz-mcp
            healthcheck:
              test: ["CMD", "curl", "-f", "http://localhost:8090/livez"]
              interval: 10s
              timeout: 5s
              retries: 3
```

## sentinel.Dockerfile

**Location:** `deploy/sentinel.Dockerfile`

**Contents:**
```dockerfile
FROM python:3.11-slim

WORKDIR /app

# Install Sentinel
COPY pyproject.toml ./
COPY src/ ./src/
RUN pip install -e .

# Create non-root user
RUN useradd -m sentinel
USER sentinel

# Copy remaining files
COPY . .

# Expose port
EXPOSE 8090

# Health check
HEALTHCHECK --interval=10s --timeout=5s --start-period=5s --retries=3 \
  CMD curl -f http://localhost:8090/livez || exit 1

# Run Sentinel
CMD ["sentinel", "--port", "8090"]
```

## Deployment Steps

### 1. Install Foundry
```bash
curl -fsSL https://signoz.io/foundry.sh | bash
```

### 2. Validate Casting
```bash
foundryctl gauge -f casting.yaml
```

Expected: All checks pass (Docker, ports, etc.)

### 3. Generate and Deploy
```bash
# Generate Compose files
foundryctl forge -f casting.yaml

# Or full pipeline (validate + generate + deploy)
foundryctl cast -f casting.yaml
```

### 4. Verify
```bash
# Check containers
docker ps

# Expected containers:
# - signoz-telemetrystore-clickhouse
# - signoz-metastore-postgres
# - signoz-telemetrykeeper-clickhousekeeper
# - signoz-ingester (OTel Collector)
# - signoz-signoz (UI)
# - signoz-mcp (MCP Server)
# - sentinel (our service)

# Check health
curl -fsS http://localhost:8080/api/v1/health  # SigNoz UI
curl -fsS http://localhost:8000/livez          # MCP Server
curl -fsS http://localhost:8090/livez          # Sentinel
```

## Environment Variables

**SigNoz Defaults (from Foundry):**
- SigNoz UI: `http://localhost:8080`
- OTel Collector: `http://localhost:4317` (gRPC), `http://localhost:4318` (HTTP)
- MCP Server: `http://localhost:8000/mcp`

**Sentinel:**
| Variable | Source | Purpose |
|----------|--------|---------|
| `SENTINEL_WEBHOOK_SECRET` | User-provided | HMAC secret for webhooks |
| `SENTINEL_DB_PATH` | `/data/sentinel.db` | SQLite database |
| `SENTINEL_OTEL_ENDPOINT` | `http://signoz-ingester:4317` | OTel export |
| `SENTINEL_DRY_RUN` | `true` | Safe default |

## Reproducibility Requirements

**MUST:**
1. `casting.yaml` is committed
2. `casting.yaml.lock` is committed (generated by Foundry)
3. `pours/` directory is NOT committed (generated, not source)
4. Fresh `foundryctl cast -f casting.yaml` works without manual edits

**Verification:**
```bash
# Clean state
rm -rf pours/ sentinel-data/

# Deploy
foundryctl cast -f casting.yaml

# Verify
curl -fsS http://localhost:8090/livez
```

## Files
- `casting.yaml` — Foundry casting file
- `casting.yaml.lock` — Generated lockfile (committed)
- `deploy/sentinel.Dockerfile` — Sentinel container

- `foundryctl gauge -f casting.yaml` passes
- `foundryctl cast -f casting.yaml` deploys successfully
- All expected containers are running
